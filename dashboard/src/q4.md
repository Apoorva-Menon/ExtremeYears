# Bursts or prolonged exposure

### Are extreme years brief bursts of intense irradiation or prolonged exposure?

```js
import {
  peakConfig, swarmConfig,
  drawPeakHistogram, drawBeeswarm, columnOf, rowOf, drawHeatmap
} from "./components/q3-q4.js";
```

```js
const planets = FileAttachment("data/planets_story.csv").csv({typed: true});
```

#### 1. Number of planets at different peak starlight values

```js
//percentage slider
const topPercent = view(Inputs.range([1, 50], {
  label: "Extreme = top %",
  step: 1,
  value: peakConfig.defaultTopPercent
}));
```

```js
//get peak values
const peakValues = planets.filter(d => d.S_peak > 0).map(d => d.S_peak);

//sort the peaks
const sortedPeaks = peakValues.slice().sort(d3.ascending);
```

```js
//cutoff starlight after which it is all extremes
const cutoff = d3.quantileSorted(sortedPeaks, 1 - topPercent / 100);  //topPercent - current % value from the slider

//extreme peak values
const extremeCount = peakValues.filter(d => d >= cutoff).length;
```

The top **${topPercent}%** of planets (**${extremeCount.toLocaleString()}**) receive at least **${d3.format(",.0f")(cutoff)}×** Earth's starlight at their closest approach. These are the "extreme" years used in the next chart.

```js
display(drawPeakHistogram(peakValues, cutoff));
```

#### 2. Bursts vs prolonged exposure among the extreme planets

```js
//planets which have the peak starlight above the cutoff
const extremePlanets = planets.filter(d => d.S_peak >= cutoff);

// planets who spent their most of their year at peak
const fullYearPlanets = extremePlanets.filter(d => d.above_half_peak_time >= swarmConfig.fullYearShare);

// planets not considered fullYearPlanets
const swarmPlanets = extremePlanets.filter(d => d.above_half_peak_time < swarmConfig.fullYearShare);

const burstPlanets = extremePlanets.filter(d => d.above_half_peak_time < swarmConfig.burstShare);
```

```js
display(drawBeeswarm(swarmPlanets, fullYearPlanets));
```

Of the **${extremePlanets.length.toLocaleString()}** extreme planets, only **${burstPlanets.length}** (${d3.format(".0%")(burstPlanets.length / extremePlanets.length)}) get their starlight in brief bursts. The rest stay near their peak for a large part of the year, or all of it.

#### 3. A closer look at which planets experience extreme bursts, given their eccentricity

```js
const heatPlanets = planets.filter(d => d.S_peak > 0);

const burstEcc = d3.min(planets.filter(d => d.exposure === "burst"), d => d.e);

const heatCells = d3.flatRollup(
  heatPlanets,
  group => group.length,
  columnOf,
  rowOf
).map(([column, row, count]) => ({column, row, count}));
```

```js
display(drawHeatmap(heatCells, cutoff, burstEcc));
```
