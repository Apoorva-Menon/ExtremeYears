# Eccentricity & starlight

### How does eccentricity affect the starlight a planet receives?

```js
import {graphConfig, drawHistogram, relativeStarlight, drawLightCurve} from "./components/q3-q4.js";
```

```js
const planets = FileAttachment("data/planets_story.csv").csv({typed: true});
```

```js
// filtering the measured eccentricity of the planets
const measuredEcc = planets.filter(d => d.e_quality === "measured").map(d => d.e);
```

```js
// draws slider
// ecc - holds current slider number
const ecc = view(Inputs.range([0, graphConfig.maxEcc], {
  label: "Eccentricity",
  step: 0.01,
  value: 0.5
}));
```

```js
//computing the data points for the light curve
const lightCurvePoints = d3.range(graphConfig.timeSteps + 1).map(step => {
  const t = step / graphConfig.timeSteps;
  return {t: t, starlight: relativeStarlight(t, ecc)}; //ecc - current eccentricity on slider
});
```

```js
display(drawHistogram(measuredEcc, ecc));
```

```js
display(drawLightCurve(lightCurvePoints));
```
